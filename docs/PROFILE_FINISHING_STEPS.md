# GitHub profile finishing steps

The profile README and repository branding assets are published. A few account-level settings must be applied in GitHub's web interface because the connected GitHub actions do not expose profile-settings, avatar-upload, social-preview-setting, or pin-management operations.

## Profile avatar

1. Download `arshia-github-avatar.png` from the assistant-provided file link.
2. Open GitHub → Settings → Public profile.
3. Change the profile picture and upload the PNG.
4. Save the changes.

The avatar is a geometric AT monogram, not a generated portrait.

## Bio and profile details

In GitHub → Settings → Public profile:
- Name: `Arshia Taheri`
- Bio: `Software Engineer | AI Engineer`
- Pronouns: leave unspecified unless you choose otherwise.
- Public email: keep hidden unless you intentionally want it public.
- Social account: add the LinkedIn profile supplied for this portfolio.

## Social preview for this profile repository

1. Download `arshia-github-social-preview.png`.
2. Open this repository → Settings → General.
3. Find Social preview and choose Edit.
4. Upload the PNG and save.

The social preview applies when the repository link is shared; it is not a profile-page cover banner.

## Pinned repositories

Do not pin empty or roadmap-only repositories as if they were finished engineering projects. Once the first implementation is public, open the profile → Customize your pins and select the repositories with working code, tests, and clear READMEs.
