Built for grounded retrieval

Make internal knowledge usable.

A retrieval layer that prioritizes source traceability, clear tenant boundaries and predictable integration over black-box answers.

01 / SOURCE-AWARE

Citations by design

Retrieve ranked document evidence and return source references so downstream applications can show where information came from.

02 / TENANT-ISOLATED

Separate customer spaces

API keys map to tenant identities. Ingestion, listing, deletion and retrieval are scoped to the authenticated tenant.

03 / OPERABLE

Production-minded API

PostgreSQL full-text search, protected metrics, privacy-conscious audit events and health checks support real integrations.

How it fits together

One retrieval layer. Clear boundaries.

AtlasRAG provides the evidence retrieval foundation that an application can use before composing its own response or workflow.

Current main-branch search uses PostgreSQL lexical full-text retrieval. Semantic/vector and hybrid retrieval are not represented as currently released functionality.

Trust boundaries

Isolation is part of the product.

Authentication is fail-closed, cross-tenant document access is blocked, and audit events avoid storing API keys, raw query text or document bodies. Review the implementation and deployment runbook before production use.
