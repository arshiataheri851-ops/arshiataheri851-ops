The platform

From raw feedback to a useful signal.

A deliberately focused service: normalize Persian text carefully, validate requests, run a pinned model and return a typed response.

01

Persian-aware processing

Conservative text normalization handles common Arabic/Persian character variants while preserving meaningful ZWNJ characters.

02

Simple REST contracts

Typed single-text and batch endpoints, bounded batch size, clear validation and health checks for dependable integration.

03

Operational controls

Lazy model loading, API-key protection, CPU and batch controls, non-root Docker image and automated tests.
